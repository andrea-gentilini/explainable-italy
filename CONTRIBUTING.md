# Contribuire a Explainable Italy

Explainable Italy è un progetto open source nato per aiutare le persone a leggere dati pubblici senza doversi orientare tra portali e classificazioni tecniche.

Ogni contributo è benvenuto. Puoi:

- segnalare un dato o un collegamento che non funziona;
- proporre una fonte pubblica utile;
- migliorare testi, traduzioni o accessibilità;
- correggere o sviluppare il codice.

Puoi aprire una issue oppure inviare direttamente una pull request. Non serve una proposta formale: per le modifiche ai dati è semplicemente utile includere il collegamento alla fonte ufficiale, così il cambiamento può essere verificato.

## Lavorare sul progetto

Il progetto usa Node.js e pnpm. I controlli disponibili sono:

```bash
pnpm lint
pnpm test
```

Grazie a chiunque dedichi tempo, attenzione o una segnalazione al progetto.
