# Contributing to Explainable Italy

You can write in English or Italian. Choose the form that fits your contribution:

- [Report a data or link issue](https://github.com/andrea-gentilini/explainable-italy/issues/new?template=bug.yml). Include the affected page and what you found. A source link helps us verify a data correction.
- [Suggest a public source](https://github.com/andrea-gentilini/explainable-italy/issues/new?template=indicator.yml). Link to the official dataset and describe the question it could help answer.
- [Suggest an improvement](https://github.com/andrea-gentilini/explainable-italy/issues/new?template=improvement.yml). Propose a change to wording, translations, accessibility or code.

GitHub requires an account to submit a report. Issues and replies are public.

## Contribuire in italiano

Puoi usare gli stessi moduli e scrivere in italiano:

- [Segnala un dato o un collegamento](https://github.com/andrea-gentilini/explainable-italy/issues/new?template=bug.yml), indicando la pagina e il problema. Per correggere un dato è utile il collegamento alla fonte ufficiale.
- [Proponi una fonte pubblica](https://github.com/andrea-gentilini/explainable-italy/issues/new?template=indicator.yml), con il collegamento al dataset ufficiale e la domanda a cui potrebbe rispondere.
- [Proponi un miglioramento](https://github.com/andrea-gentilini/explainable-italy/issues/new?template=improvement.yml) a testi, traduzioni, accessibilità o codice.

Per inviare una segnalazione serve un account GitHub. Le segnalazioni e le risposte sono pubbliche.

## Code contributions / Contributi al codice

You can open a pull request directly. Describe the change and how you checked it. For changes to data or definitions, include an official source so the result can be verified.

Puoi aprire direttamente una pull request. Descrivi la modifica e come l’hai verificata. Per dati e definizioni, includi una fonte ufficiale che permetta di controllare il risultato.

Follow the setup instructions in the [English README](README.md#run-locally) (linked also from the [Italian guide](README.it.md#per-chi-contribuisce--segnalazioni-codice-e-manutenzione-tecnica)). Run the project checks before opening a pull request:

```sh
pnpm check
```

These checks cover code style, data validation, the production build and tests. I controlli includono stile del codice, validazione dei dati, compilazione e test.
